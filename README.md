# The Mind Artists - Task 1

Instructions:
1. Use a public API such as https://jsonplaceholder.typicode.com/posts to
fetch data.
2. Render a list of cards showing each post’s title and body.
3. Include an image in each card. If no image is available, display a default placeholder
(e.g., https://placehold.co/400).
4. Style the cards in a purple gradient aesthetic that matches https://themindartists.com,
using Tailwind CSS or your preferred method.
